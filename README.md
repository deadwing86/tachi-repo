# Personal Tachiyomi Extension Repo

A self-hosted repository of Tachiyomi/Mihon extensions removed from keiyoushi.

## How to add in Mihon

1. Open Mihon → **Browse** → **Extension repos** (top-right gear icon)
2. Add this URL:
   ```
   https://raw.githubusercontent.com/deadwing86/tachi-repo/repo/index.min.json
   ```
3. Go to **Browse → Extensions** and install as normal

## Updating

Push changes to `main` — GitHub Actions will automatically build the APK and update the index.
